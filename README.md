# firmware-released

Released firmware images for GRE Systems chargers, published as GitHub Releases.

| Product | Release tag | Assets |
|---|---|---|
| CP700P-L Standalone | `cp700pl-standalone-v<version>` | `cp700pl.bin`, `manifest.json` (version, size, SHA-256) |

Devices find their releases by the tag prefix, so several products can share this repository.
